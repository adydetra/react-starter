# Project Status & Roadmap

Current state, supported features, and technical notes for `react-starter`.

## Implemented Scope

- **React 19 + Vite 8**: Modern React setup with lightning-fast HMR.
- **Tailwind CSS v4**: Zero-configuration Vite plugin `@tailwindcss/vite`.
- **State Management**: Pre-configured with Zustand for reactive global state.
- **TypeScript**: Solution-based TSConfig setup with strict compiler options.
- **ESLint**: Modern flat config with `eslint-plugin-react-hooks` and `eslint-plugin-react-refresh`.

## Roadmap

- [ ] Vitest and React Testing Library setup for unit testing.
- [ ] GitHub Actions CI workflow for automated linting and build checks.
- [ ] Atomic component structure examples (Atoms, Molecules, Organisms).
